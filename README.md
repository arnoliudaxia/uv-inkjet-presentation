# 微观之间 · UV 打印喷头课堂

精美中文网页版动画 PPT，共 3 页。原生 HTML / CSS / JavaScript 与 SVG，Node.js 服务端零外部依赖，不使用 CDN、网络字体或外部图片。适合本地教学、投屏与离线演示。

## 启动

需要 Node.js 18 或更新版本，无需执行 `npm install`。

```bash
npm start
```

打开 **http://127.0.0.1:3000**。服务只绑定 `127.0.0.1`，不会监听局域网接口。修改端口：

```bash
PORT=3100 npm start
```

停止服务：终端按 `Ctrl+C`。

## 内容与使用

1. **结构认识**：主视觉为 SVG 单通道剖面。供应管道、墨腔和底部喷嘴用一个连续封闭的墨水路径绘制；另标出墨腔与可变形腔壁。初始呈现低亮度完整结构；前进三次，依次突出供应管道、压电陶瓷、喷嘴；再前进进入第二页。点击图中部件或右侧卡片可直接揭示至对应部件，并阅读说明。后退可逐个收起。
2. **喷墨循环**：补墨与扩容 → 压缩与压力波 → 喷出与断滴 → 恢复与回填。显示腔壁形变、简化压力扰动、液柱和离开喷嘴的墨滴。可暂停播放；点击阶段按钮会暂停并定位该阶段中段。
3. **驱动波形**：概念信号曲线、SVG 游标和喷头响应共用一个循环时钟。标记扩容、压缩、喷出/过渡、恢复阶段；与第二页切换时保持进度和播放状态。可播放、暂停或手动跳至下一阶段。

桌面以 16:9 画布展示；窄屏转换为纵向阅读布局，避免挤压文字；全屏时优先利用屏幕空间，16:9 屏幕可铺满。进入全屏仍保留所有操作按钮。

## 快捷键

| 操作 | 快捷键 / 控件 |
| --- | --- |
| 下一步 / 下一页 | `→`、`PageDown`、`Space`、右下角按钮 |
| 上一步 / 上一页 | `←`、`PageUp`、左箭头按钮 |
| 直接跳页 | 底部 `01` / `02` / `03`；也可访问 `/#1`、`/#2`、`/#3` |
| 切换全屏 | `F`、右上角全屏按钮 |
| 查看帮助 | `?`、右上角帮助按钮 |
| 关闭帮助 / 退出全屏 | `Esc`（浏览器原生行为） |
| 键盘操作部件 / 按钮 | `Tab` 聚焦，`Enter` 或 `Space` 激活 |

当焦点在按钮或部件上，空格保留原生激活语义，不重复触发全局翻页。页面隐藏、打开帮助或停留首页时不推进循环。遵循 `prefers-reduced-motion`：禁用装饰过渡与流线动画、默认暂停；仍可手动选择阶段，或主动点击播放。切换为减少动态效果时会自动暂停。

## 文件

- `package.json`：启动与语法检查脚本，无 dependencies。
- `server.mjs`：Node.js HTTP 静态服务；支持 GET / HEAD、MIME、请求错误处理和静态文件白名单。不会暴露 README、服务代码或其他磁盘文件。
- `index.html`：三页内容、导航、帮助对话框和无障碍语义。
- `styles.css`：暗色科技教学视觉、中文排版、响应式布局及减少动态效果适配。
- `app.js`：SVG 剖面、部件揭示、循环时钟、波形同步、键盘与全屏交互。
- `README.md`：使用与技术说明。

## 技术示意的边界（重要）

- 展示的是一种**简化的压电按需喷墨工作原理**，不指向任何品牌或具体型号。实际有弯曲、剪切等不同压电驱动结构，供墨与回流结构也可能不同。
- 图中尺寸、材料厚度、位移、墨滴形状及动画时长均非真实比例；形变为便于观察而夸张。金色表示压电执行器，青色表示墨水，不代表实际材料颜色。
- 波形仅为概念性节奏示意：没有实际电压、微秒时序或调机数值，不能用于驱动硬件。横纵轴均归一化。
- **形变方向取决于喷头结构、安装约束和驱动极性，不能把“电压高”理解为“必然喷墨”。** 示意扩容/压缩阶段描述本图机械状态，不是通用电压极性规则。
- 实际喷射取决于压力波传播与反射、声学匹配、液面响应、墨水黏度/表面张力、温度、背压及波形参数等。压力扰动图形是教学符号，不是流体计算结果。
- 补墨、压力传播、断滴与恢复在实际过程中可能交叠，动画的四阶段为了讲解而分段。UV 固化、喷头阵列、过滤、脱气和完整供墨控制系统不在此图范围内。

curl -I http://127.0.0.1:3000/app.js
