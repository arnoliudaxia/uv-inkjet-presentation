# 从层高差异到单滴控制 · Slidev

9 页中文 UV 多材料打印动画演示，使用 Slidev、Vue 和 SVG。白/浅灰背景、深蓝灰正文，高饱和蓝青/洋红/亮黄/蓝紫墨水配色、无常驻导航栏，键盘推进叙事，图示不依赖外部图片、字体或 CDN。

## 启动

需要 Node.js 22.12+（推荐 24）和 npm。

```bash
npm ci
npm start
```

打开 http://127.0.0.1:3000 。已有后台服务时直接刷新，不要重复启动。开发服务仅绑定本机回环地址，端口占用时退出，不自动改端口。Slidev 53.1 不支持 CLI `--host`，绑定由 `vite.config.ts` 控制。macOS/Linux 启动脚本显式设置 `NODE_ENV=development`；Windows 建议使用 WSL。

画布 1440×810，按视口等比缩放。非 16:9 视口会留浅色边，避免拉伸/裁切；推荐横屏或投屏。隐藏 Slidev 工具栏、品牌、页码与帮助按钮，仅保留波形参数、阶段定位等教学控件。

第一页每色悬空 3 滴，C:M:Y:支撑 S 的单滴体积比为 0.5:1:1:2；显示半径按 `18 × V^0.65` 非线性夸张（非真实球体比例），使大小差异更容易辨认；数字体积和沉积层厚不受夸张影响。一次推进后液滴落下、渐隐并合成四个相邻颜色层区；同数量、同落点密度、同投影面积且体积保留的假设下，层厚比同为 0.5:1:1:2。可后退恢复，减少动态效果偏好下直接切换终态，右侧仅一块动态说明。

第二页色块仅示意用户图中的相对高度关系，C:M:Y:支撑 S ≈ 1:2:2:4；以 M/Y 为 1.00，初始归一化高度为 0.50、1.00、1.00、2.00，补偿基准为最低 C 0.50。所有数值、表面图、墨滴和波形均为**教学示意，不是实验数据或硬件参数**，不代表固定的材料性能排序。第二页为 2 clicks（仍为同一物理页，全套仍 9 页）：`/2`（click 0，内部 step 2）直接显示原始高度轮廓和补偿比例：C 100%、M 50%、Y 50%、S 25%；不加补偿目标或参考目标文字。10 层依次瞬间出现，每层内部无缩放动画；y=308 的目标线在初始堆叠完成后才出现（delay 1.36s），侧栏仅显示“通过测量高度，计算补偿比例。”。`/2?clicks=1`（内部 step 3）主标题与顶部 panel label 均为“液体流动补缺”：在 blocks SVG 内使用独立单色分支，不与前后四色块衔接。仅一块鲜青 `#00a6df` 液体，`retain=.5`；16 个等宽列交替为高 144 与空缺，用同一进度平滑插值至 72。`FlowLeveling` 参数化宽度 650、基底 y=342，横向居中（x=105），不缩放文字或描边；任意帧截面积均为 650×72=46800，而非淡入替换或缩放增量。2.6 秒内高柱下降、8 处空缺液面上升直至平齐，深色箭头强调横向补缺。不显示 C/M/Y/S 名称、数值、目标线、四色补偿比例或点阵。唯一侧栏标题“液体流动补缺”，正文“未固化墨水横向流动，逐渐填补空缺。”；不增加 UI。通过 `useSlideContext` 监听 clicks、当前页及渲染上下文，仅进入本页 click 1 播放，后退再进入重播；离页、卸载、隐藏标签页取消 RAF，reduced-motion 直接显示终态。`data-progress`、`data-running`、`data-heights`、`data-initial-heights` 和初始/当前/最终面积代理用于测试。`/2?clicks=2`（内部 step 4）立即显示等效平均高度全部为 0.50：每色仅单个 `rect.solid-block`，x=0、y=308、width=106、height=72，不再有 10 层分隔；虚框 y=307、高 72，目标线立即可见。再推进才进入 `/3`，主标题保持用户文字“补偿后等效平均高度一致”（无标点）。下方固定示意点阵每色基准 32 点，仅一组：C 保持 32 点，M/Y 各抽点后保留 16 点（50%），S 保留 8 点（25%），无 C 额外喷射点组。唯一右侧卡片保留终态标题“等效平均高度一致”，正文为“C 不变，M/Y 抽点后保留 50%，S 保留 25%。”，不增加底部说明或额外 UI。旧的读高度、计算比例和固定掩模展示不再作为单独推进步骤。这是高度与沉积次数成比例的区域平均沉积量教学模型，非真实表面仿真。随机混色局限留在第三页。所有阶段可后退恢复。原单层截面及独立标定组件旧模式保留备用。

### 操作

- `→` / `Space` / `PageDown`：下一步，完成当前页步骤后翻页。
- `←` / `Shift+Space` / `PageUp`：后退。
- `↓` / `↑` 或 `Shift+→` / `Shift+←`：跳过步骤翻页。
- 直接访问 `/1` 至 `/9`；[`/5?clicks=2`](/5?clicks=2) 定位结构页第二步（链接相对演示服务根路径）。
- 教学按钮支持点击、Tab、Enter、Space；聚焦按钮后空格用于激活，不额外翻页。
- 使用浏览器全屏或 Slidev 原生 `F`。没有常驻全屏按钮。

减少动态效果偏好会关闭过渡，喷射默认暂停，仍可手动定位阶段或主动播放；喷射循环只在相关页面可见时推进。

## 构建与测试

```bash
npm run check       # JS 语法检查 + 生产构建
npm run build       # 静态输出 dist/
npx vite preview --host 127.0.0.1 --port 3102
TEST_URL=http://127.0.0.1:3000 npm run test:browser
```

浏览器测试使用 `playwright-core` 与本机 Chrome，默认路径为 macOS Google Chrome。其他环境通过 `CHROME_PATH` 指定。测试不负责启动/关闭服务，默认目标为 3101，可通过 `TEST_URL` 修改。

部署 `dist/`，不要将开发服务暴露到公网。history 路由需要将未知路径回退到 `index.html`；构建包含 `404.html` 和 `_redirects`。不能直接双击 HTML 用 `file://` 打开。子路径部署可用 `npm run build -- --base /demo/`。

## 技术边界

- 不同配方在相同驱动下可能有不同的滴量、形态与固化层高；不能仅由颜色推断性能。黏度、表面张力、温度、背压、润湿、合滴与固化收缩也会影响结果。
- 抽点补偿可控制区域平均沉积量，但块体标定不能直接保证随机混色的局部平整；本演示不否定经过空间建模和实测验证的抽点策略。
- 波形有助于改善单滴与喷射一致性，不是固化表面平整的充分条件；需联合检查滴量、速度、卫星滴和喷射稳定性，再测固化形貌。
- 喷头剖面为简化压电按需喷墨通道，不对应型号。位移夸大，压力图不是流体仿真。
- “拉—保持—推—恢复”示例选择上升沿扩容的极性；实际方向依结构、安装约束和极性。四段等时和八秒循环仅方便观察，真实压力存在传播/反射延迟，阶段可能交叠。参数探索不提供实际电压或微秒时序，也不预测滴量单调关系。
- 测量需求区分横向分辨率（目标约 1 μm）、高度分辨率/重复性（待定）、Z 量程（至少 100 μm）和视场（待定）。AFM 并非默认满足该组合；共聚焦、白光干涉、色散共焦亦需按样品和设备验证。
- 没有加入 PDF/视频导出；静态 PDF 不能保留交互动画。
- 上次依赖审计仍报告 8 项问题（3 low、4 high、1 critical），涉及 Slidev 上游依赖链，尚未通过破坏性升级解决。已关闭编辑、导出、录制等非必要功能，但关闭功能不等于修复漏洞。只播放可信本地课件，不开放开发服务到公网，不加载不可信内容；升级后需重新审计。
